# Flesh Spread (Forge 1.20.1) — сабмод для Flesh That Hates

Що виправляє: у Flesh That Hates інфекція природно з'являється лише з 3-ї доби (dayTime >= 72000) і лише через
заражених розбійників. Цей мод:
1. розкидає гнізда (малі інкубатори) у нових чанках з самого початку, з невеликою зараженою плямою навколо;
2. з часом (з 1-ї доби) тримає гнізда навколо кожного гравця, їх кількість росте з днями;
3. малі інкубатори самі дорослішають у великі через ripenDays (великий дає у 5 разів частіше спавнери мобів).

Налаштування: config/flesh_spread.json. Команди (оп): /flesh_spread seed, /flesh_spread nearest.
Збірка: GitHub Actions -> build -> Artifacts. Потрібні Forge 47.x і Flesh That Hates.
